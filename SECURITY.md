# Security Policy

## Supported Versions

Here are all the currently supported versions of `hjlix`.

| Version | Supported          |
| ------- | ------------------ |
| <0.1.5.2   | :x:                |
| 0.1.5-2    | :white_check_mark: |

## Reporting a Vulnerability

Report a vulnerability by opening a pull request.
Look at the [Code of Conduct](./CODE_OF_CONDUCT.md) and in [how to contribute](./CONTRIBUTING.md).
