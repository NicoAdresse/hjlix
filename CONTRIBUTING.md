# Contributing to hjlix

Thank you for considering contributing to `hjlix`! We truly appreciate your time and effort in helping make this project better.

Please follow these guidelines to ensure a smooth contribution process:

## 1. Create a New Git Branch
When working on a bug fix or a new feature, always create a dedicated branch from `main`:
```bash
git checkout -b feature/your-feature-name
# or for bug fixes:
git checkout -b fix/your-bug-fix-name
```
Keep your changes **atomic and small** (focused on a single bug fix or feature) to make code review easier.

## 2. Test Code Changes
Before submitting your changes, ensure that your code builds successfully and doesn't receive a compiler rror.
```bash
cargo build --release
```

## 3. Open a Pull Request
Push your branch to your fork or remote repository and open a Pull Request (PR) against the `main` branch of `hjlix`. Provide a clear and concise description of what your pull request accomplishes.

## 4. Wait Patiently
Once your pull request is open, please wait patiently for a moderator/maintainer to review and accept your contribution. Thank you again for your support!
